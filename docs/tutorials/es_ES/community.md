# Tutoriales de la comunidad

- [Authentication and Authorization with hapi](https://medium.com/@poeticninja/authentication-and-authorization-with-hapi-5529b5ecc8ec)

    Artículo sobre cómo proteger tu aplicación hapi.

- [Building a Chat Application with hapi.js, Socket.io and Redis](https://github.com/dwyl/hapi-socketio-redis-chat-example)

    Aplicación de chat en tiempo real construida con hapi.js, Socket.io y Redis Pub/Sub, con tests end-to-end.

- [Building a modern backend with TypeScript, Hapi, PostgreSQL and Prisma](https://www.prisma.io/blog/series/modern-backend-bdes2ps5kibb)

    Una serie de directos y artículos sobre cómo construir un backend con TypeScript, Hapi, PostgreSQL y Prisma.
    La serie cubre modelado de datos, CRUD, agregaciones, REST, validación con Joi, testing, autenticación, autorización, integración con otras APIs, e integración y despliegue continuos con GitHub Actions y Heroku.
    La serie explora y muestra distintos patrones, problemas y arquitecturas para un backend moderno resolviendo un problema concreto: un sistema de calificaciones para cursos online. Es un buen ejemplo porque incluye relaciones de tipos diversos y es lo bastante complejo como para representar un caso de uso real.

- [Handling plugin dependencies](https://hapipal.com/best-practices/handling-plugin-dependencies)

    Partiendo de los límites entre plugins de hapi, este artículo propone una forma concreta de controlar las dependencias entre plugins.

- [hapi tutorial series (30+ tutorials)](https://futurestud.io/tutorials/hapi-get-your-server-up-and-running)

    Esta serie de tutoriales en profundidad sobre hapi cubre la configuración de rutas, la autenticación, los plugins, el manejo de peticiones y respuestas, y mucho más.

- [hapi.js tutorials covering various topics](https://content.nanobox.io/tag/hapi.js/)

    Una lista creciente de tutoriales sobre desarrollo, despliegue, optimización y gestión en producción (escalado, monitorización, etc.) de aplicaciones hapi.js.

- [How to create a REST API with hapi](http://blog.webkid.io/how-to-create-a-rest-api-with-hapi/)

    Tutorial sobre cómo crear una API REST con los plugins Dogwater (ORM Waterline) y Bedwetter.

- [The joys of server / plugin separation](https://hapipal.com/best-practices/server-plugin-separation)

    Separar el plugin de tu aplicación de su despliegue hace que tu app hapi sea más portable y más fácil de testear.

- [rate-limiter-flexible-plugin-example](https://github.com/animir/node-rate-limiter-flexible/wiki/Hapi-plugin)

    Ejemplo de plugin de limitación de peticiones y protección contra DDoS con el paquete rate-limiter-flexible.

- [Run hapi.js on Google Cloud Platform](https://cloud.google.com/nodejs/resources/frameworks/hapi)

    Tutorial y aplicación de ejemplo clonable que muestra cómo crear y desplegar una aplicación hapi.js en Google App Engine.

- [Catbox-Redis and Cookie Auth Example](https://github.com/johnmanko/catbox-redis-example)

    Muestra cómo usar @hapi/catbox-redis y @hapi/cookie.

- [WittCode's Hapi Tutorial Series](https://youtube.com/playlist?list=PLkqiWyX-_LotaQ9AuppIAXl0xyV-P5Ms-)

    10 vídeos que empiezan por crear un servidor Hapi, añadir rutas y plugins, y llegan hasta el uso de Sequelize/MySQL y la autenticación por cookie.
