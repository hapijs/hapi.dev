# Tutoriais da comunidade

- [Authentication and Authorization with hapi](https://medium.com/@poeticninja/authentication-and-authorization-with-hapi-5529b5ecc8ec)

    Artigo sobre como proteger sua aplicação hapi.

- [Building a Chat Application with hapi.js, Socket.io and Redis](https://github.com/dwyl/hapi-socketio-redis-chat-example)

    Aplicação de chat em tempo real construída com hapi.js, Socket.io e Redis Pub/Sub, com testes end-to-end.

- [Building a modern backend with TypeScript, Hapi, PostgreSQL and Prisma](https://www.prisma.io/blog/series/modern-backend-bdes2ps5kibb)

    Uma série de transmissões ao vivo e artigos sobre como construir um backend com TypeScript, Hapi, PostgreSQL e Prisma.
    A série cobre modelagem de dados, CRUD, agregações, REST, validação com Joi, testes, autenticação, autorização, integração com outras APIs e integração e entrega contínuas com GitHub Actions e Heroku.
    A série explora e demonstra diferentes padrões, problemas e arquiteturas para um backend moderno resolvendo um problema concreto: um sistema de notas para cursos online. É um bom exemplo porque inclui relações de tipos variados e é complexo o bastante para representar um caso de uso real.

- [Handling plugin dependencies](https://hapipal.com/best-practices/handling-plugin-dependencies)

    Partindo dos limites entre plugins do hapi, este artigo propõe uma forma concreta de controlar as dependências entre plugins.

- [hapi tutorial series (30+ tutorials)](https://futurestud.io/tutorials/hapi-get-your-server-up-and-running)

    Esta série de tutoriais aprofundados sobre hapi cobre configuração de rotas, autenticação, plugins, tratamento de requisições e respostas, e muito mais.

- [hapi.js tutorials covering various topics](https://content.nanobox.io/tag/hapi.js/)

    Uma lista crescente de tutoriais sobre desenvolvimento, deploy, otimização e gestão em produção (escalabilidade, monitoramento etc.) de aplicações hapi.js.

- [How to create a REST API with hapi](http://blog.webkid.io/how-to-create-a-rest-api-with-hapi/)

    Tutorial sobre como criar uma API RESTful com os plugins Dogwater (ORM Waterline) e Bedwetter.

- [The joys of server / plugin separation](https://hapipal.com/best-practices/server-plugin-separation)

    Separar o plugin da sua aplicação do seu deploy deixa seu app hapi mais portável e mais fácil de testar.

- [rate-limiter-flexible-plugin-example](https://github.com/animir/node-rate-limiter-flexible/wiki/Hapi-plugin)

    Exemplo de plugin de limitação de requisições e proteção contra DDoS com o pacote rate-limiter-flexible.

- [Run hapi.js on Google Cloud Platform](https://cloud.google.com/nodejs/resources/frameworks/hapi)

    Tutorial e aplicação de exemplo clonável que mostra como criar uma aplicação hapi.js e fazer o deploy no Google App Engine.

- [Catbox-Redis and Cookie Auth Example](https://github.com/johnmanko/catbox-redis-example)

    Mostra como usar @hapi/catbox-redis e @hapi/cookie.

- [WittCode's Hapi Tutorial Series](https://youtube.com/playlist?list=PLkqiWyX-_LotaQ9AuppIAXl0xyV-P5Ms-)

    10 vídeos que começam pela criação de um servidor Hapi, passam pela adição de rotas e plugins e chegam ao uso de Sequelize/MySQL e da autenticação por cookie.
